# skeo-instagram

Immagini dei caroselli Instagram di [Skeo](https://skeo.it), il CRM leggero per i lead di Facebook e Instagram.

Le cartelle in `caroselli/` sono una per post, con le schede in ordine (`01.jpg` è la copertina). Metricool le legge da qui per la pubblicazione: non rinominarle finché i post non sono usciti.
